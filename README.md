# Sistema-Prediccion-Comercio

Sistema de predicción de demanda para MIPYMES del comercio minorista fronterizo de Norte de Santander, con machine learning (SARIMA, Prophet, LSTM) y cómputo paralelo (OpenMP, MPI, CUDA). Proyecto de Ingeniería de Sistemas, Universidad de Pamplona, 2026-2.
